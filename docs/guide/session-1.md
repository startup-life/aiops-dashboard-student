# 1회차 보충 문서: 화면 틀 만들기

> 이 문서는 1회차 프롬프트가 만드는 내용의 자세한 약속입니다. 1회차가 첫 문서입니다. 뒤 회차 문서가 다르게 적으면 뒤 문서를 따릅니다.

## 이 문서를 읽는 법

- 백틱 안의 글은 이름이나 값입니다. 글자 그대로 씁니다.
- 큰따옴표 안의 글은 화면에 나오는 글자이거나 코드에 들어가는 값입니다. 한 글자도 바꾸지 않습니다.
- "쓰는 단계"는 그 내용을 만드는 프롬프트 번호입니다. 프롬프트 맨 앞의 `[2-14]` 같은 표시가 이번 단계입니다. 그 번호가 "쓰는 단계"나 줄 앞에 적힌 내용만 만들고, 다른 번호의 내용은 그 프롬프트를 받기 전에 만들지 않습니다.
- 창고 쪽 이름은 공장 쪽 이름의 `factory`를 `warehouse`로 바꾼 같은 이름입니다.

## 이 회차에서 만드는 것

- 시작 상태: 저장소 `milestone-0`을 받은 폴더입니다. 강사가 준 파일(로고, 현장 사진 두 장, `API_CONTRACT.md`), `README.md`, `.gitignore`, `AGENTS.md`, 이 문서만 있고 화면 파일은 없습니다.
- 끝 상태: `npm.cmd start`로 화면 서버(http://127.0.0.1:4173)가 켜지고 오늘 운영 화면에 다섯 영역이 차례로 보입니다. PC에서는 생산·출고 카드가 두 열, 폭 375px에서는 한 열입니다. 숫자는 아직 고정값(생산 100개 · 목표 120개, 출고 75개 · 목표 100개)이고 버튼과 화면 이동은 2회차부터 붙입니다.
- 이번에 건드리지 않는 곳: 1회차에는 JavaScript가 없습니다. 화면을 나누는 일과 선택 상자·버튼의 동작은 만들지 않습니다.
- 순서: 1-1부터 1-10까지는 화면 파일을 만들고 꾸미기를 넣지 않습니다. 1-11부터 1-18까지는 꾸미기 파일(`public/styles.css`)만 고치고 첫 화면 파일은 더 고치지 않습니다.
- 이번 프롬프트 번호가 쓰는 단계에 있는 내용만 만듭니다. 그 내용은 화면에 보이지 않는 것까지 빠뜨리지 않습니다.

아래 항목은 지금 화면에 보이지 않습니다. 뒤 회차가 이 자리를 쓰므로 꼭 만들어 둡니다.

|---|---|---|
| JavaScript가 꺼진 브라우저용 안내 | 1-4 | 평소에 보이지 않음 |

**어떤 앱인가.** 텀블공장(텀블러 공장)의 생산·출고를 보는 운영 대시보드입니다. 화면 글은 모두 한국어입니다.

## 화면 서버

쓰는 단계: 1-2

화면 서버는 화면 파일을 보내는 작은 서버입니다. 자료는 3회차부터 이 화면 서버가 아니라 API 서버에서 받으므로, API 주소로 온 요청에는 파일을 찾지 않고 안내 문장으로 답합니다. 파일을 고친 뒤 새로고침하면 바로 보이도록 모든 응답에 저장하지 말라는 표시를 붙입니다.

### 약속

**서버를 여는 방법.** 화면 서버는 Node.js 기본 모듈(`node:http`, `node:fs`, `node:path`)만 씁니다. `127.0.0.1`에서만 엽니다. 포트는 환경 변수 `PORT`, 없으면 `4173`입니다. 켜지면 `"http://127.0.0.1:<실제 포트>"` 한 줄을 출력합니다.

**파일을 찾는 방법.** `public` 폴더는 명령을 실행한 폴더가 아니라 `serve.mjs`가 있는 폴더 기준(`../public`)으로 찾습니다. `serve.mjs`가 있는 폴더는 기본 모듈 셋만 쓰도록 `import.meta.dirname`으로 구합니다.

**주소를 읽는 방법.** 주소의 ? 뒤는 무시하고 경로를 `decodeURIComponent`로 푼 뒤 판단합니다. `/`는 `index.html`입니다.

모든 응답에 `Cache-Control: no-store`를 붙입니다. 아래 두 표의 응답이 모두 해당합니다.

**파일 종류.**

| 파일 | Content-Type |
|---|---|
| html | `text/html; charset=utf-8` |
| css | `text/css; charset=utf-8` |
| js | `text/javascript; charset=utf-8` |
| png | `image/png` |
| 그 밖 | `text/plain; charset=utf-8` |

**파일을 보내지 않는 경로.**

| 경로 | 상태 | Content-Type | 보내는 것 |
|---|---|---|---|
| `/api/`로 시작하는 경로 | `404` | `application/json; charset=utf-8` | 파일을 찾지 않고 아래 "값과 모양"의 글 |
| 없는 파일, 풀 수 없는 경로, `public` 밖을 가리키는 경로 | `404` | `text/html; charset=utf-8` | `404.html` 내용 |

### 값과 모양

`/api/`로 시작하는 경로의 응답 본문입니다.

```json
{"error":"이 서버는 화면 파일만 보냅니다. 화면은 public/config.js의 apiBaseUrl로 API 서버를 직접 부릅니다."}
```

## 머리 부분 오른쪽 자리

- "기준 시각" 선택 상자(선택지 "현재" 하나, 그 value는 빈 글자 `""`)를 둡니다.

## 화면 전체 기본 모양

쓰는 단계: 1-11

이 절부터 꾸미기 파일(`public/styles.css`)만 고칩니다. 첫 화면 파일은 더 고치지 않습니다.

### 약속

- 모든 요소는 `box-sizing: border-box`로 둡니다.
- 흰 바탕에 짙은 회색 글자, 컴퓨터 기본 글꼴 16px이고 화면 가장자리 여백은 없앱니다.
- 제목과 문단의 기본 바깥 여백을 없애고 큰 제목·중간 제목·작은 제목 순서로 크기를 줄입니다. 본문 글자와 버튼 글자는 16px입니다.
- 링크와 입력 칸은 주변 글자 모양을 따릅니다. 키보드로 이동할 때는 초록 테두리가 보이게 합니다.
- 숨긴 요소는 확실히 안 보이게 합니다(앱의 기본 약속의 `[hidden]` 규칙).
- 글자를 끌어 선택하면 바탕이 연한 초록이 됩니다.

## 카드와 버튼 링크 모양

쓰는 단계: 1-12

카드 안쪽 모양, 버튼 모양 링크, 안내 상자를 꾸밉니다.

### 약속

- 카드는 연한 회색 테두리의 둥근 흰 상자로, 상자 안 글자가 테두리에 붙지 않게 안쪽 여백을 둡니다.
- 먼저 확인할 일 상자는 기본이 연한 빨강 둥근 상자이고, 회색 상태일 때는 회색 상자입니다.
- 카드의 수량 "생산 100개"는 크고 굵게, "· 목표 120개"는 그 옆에 작은 회색 글자로 한 줄에 둡니다. 숫자는 자리마다 폭이 같은 숫자 모양으로 씁니다.
- 카드 설명과 작은 시각 글은 회색으로, 배지는 작은 둥근 꼬리표로 꾸밉니다.
- 배지는 상태 색 네 가지(초록·노랑·빨강·회색)로 칠하고 빨강 상태 카드는 연한 빨강 바탕으로 보이게 합니다. 지금 화면에는 초록 배지만 보이지만 네 가지를 모두 넣습니다.
- 카드 아래 링크는 누르기 쉬운 높이로 하고 "생산 기록 보기"·"출고 기록 보기"는 검은 버튼처럼 꾸며 마우스를 올리면 조금 옅어지게 합니다.
- 안내 상자는 회색 테두리의 둥근 상자, 노란 안내 상자는 노란 바탕입니다.

쓰는 단계: 1-17

### 약속

- 폭 700px 이하 규칙을 꾸미기 파일 맨 끝에 한 묶음으로 만들고 앞으로 휴대폰 규칙은 이 묶음에 넣습니다.

- 알림 버튼은 글자를 숨기고 종 아이콘만 머리 부분 오른쪽 위에 둡니다. 기준 시각과 새로고침은 로고 아래 줄에 나란히 놓습니다.
- 카드 묶음을 모두 한 열로 하고 카드 안 여백과 영역 간격을 조금 줄입니다.
- 생산·출고 수량 글자 크기는 바꾸지 않고 폭 375px에서 가로 스크롤이 생기지 않게 합니다.
