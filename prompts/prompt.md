# 과정별 실습 프롬프트

같은 프로젝트 폴더에서 회차와 번호 순서대로 프롬프트를 하나씩 입력합니다.

### 1회차: 화면 틀 만들기

1. 웹사이트는 내가 보내는 프롬프트에 따라 만들어줘. 다른 저장소의 제작 가이드나 완성 코드는 읽지 말아줘.
   이 폴더에서 웹 서비스를 만들 수 있게 Node.js와 Git이 있는지 확인해줘. 없으면 설치 방법을 알려줘. 설치나 로그인 중 내가 직접 해야 하는 일은 알려줘.

2. https://github.com/startup-life/aiops-dashboard-student 에서 API_CONTRACT.md와 public/assets의 tumble-factory-logo.png, approved/factory.png, approved/warehouse.png만 같은 경로로 가져와줘. 강사 API 명세와 수업용 사진이야.

3. HTML, CSS, JavaScript로 텀블공장 운영 대시보드를 만들어 내 컴퓨터에서 실행해줘. 생산과 출고의 목표·완료 수량, 현장 사진, 운영 상태와 확인할 일을 보여줘. 처음에는 수업용 예시 값을 사용해줘.

4. 컴퓨터에서는 두 열, 휴대폰에서는 한 열로 보이게 정리해줘. 값은 수업용 예시임을 표시해줘.

### 2회차: 예시 자료와 기록 화면

1. API_CONTRACT.md의 예시 자료로 생산·출고 수량과 목표 달성률, 시간별 그래프를 채워줘. 값이 없으면 0으로 단정하지 말고 확인할 수 없다고 표시해줘.

2. 생산 기록과 출고 기록 화면을 만들어 시간별 기록을 표로 보여줘. 홈에서 각 화면으로 이동하고 돌아올 수 있게 해줘.

3. 확인할 일과 알림 목록을 보여주고, 버튼과 그래프를 키보드로도 사용할 수 있게 해줘.

### 3회차: 강사 API와 과거 조회

1. API_CONTRACT.md에 적힌 강사 API를 연결해서 오늘 생산·출고 현황과 기록을 보여줘. API는 읽기 전용으로 사용하고 강사의 조작 기능은 호출하지 마.

2. 현재 자료를 10초마다 다시 조회하고 새로고침 버튼과 마지막 조회 시각을 표시해줘. 실패하면 이유를 알리고 마지막으로 받은 값은 유지해줘.

3. 기준 시각을 골라 과거 현황과 생산·출고 기록을 조회하게 해줘. 과거 자료임을 표시하고 현재로 돌아오는 버튼을 만들어줘. 조회한 시각과 성공·실패 이력도 보여줘.

### 4회차: 내 NestJS 서버

1. API_CONTRACT.md의 자료 형식에 맞춰 내 컴퓨터에서 실행하는 NestJS 서버를 만들어줘. 수업용 생산·출고 기록과 오늘 현황을 제공하고, 서버를 다시 켜도 예시 기록이 남게 해줘.

2. 대시보드의 연결 주소를 강사 API와 내 서버 중에서 바꿀 수 있게 해줘. 강사 API에서 쓰던 현황·기록·과거 조회가 내 서버에서도 작동하게 해줘.

3. 내 서버를 실행하고 화면을 연결해줘. 연결 실패나 자료 형식 오류가 나면 이유를 보여줘.

### 5회차: Google 시트와 Apps Script

1. 내 Google 시트에 수업용 생산·출고 기록을 저장하고 Google Apps Script 웹앱으로 조회하게 만들어줘. API_CONTRACT.md의 현황과 기록 형식을 유지해줘.

2. Google 로그인, Apps Script 프로젝트 생성과 배포를 도와줘. 로그인과 권한 승인은 내가 직접 할게. 이미 만든 프로젝트가 있으면 중복 생성하지 말고, 웹앱 접근 범위를 알려준 뒤 내가 확인하면 진행해줘.

3. 대시보드를 내 Apps Script 웹앱에 연결해줘. 강사 API와 내 서버 연결도 선택할 수 있게 유지하고 현재 연결 대상을 표시해줘.

### 6회차: Discord 알림과 자동 처리

1. Apps Script가 수업용 생산·출고 기록을 읽고 처리 상태와 처리 시각을 시트에 남기게 해줘. 같은 기록을 중복 처리하지 않고 원본 기록은 보존해줘.

2. 처리가 지연되거나 실패하면 내 Discord 시험 채널에 알림을 보내고 시트에 전송 결과를 남겨줘. 웹훅 주소는 내가 직접 비공개 설정에 넣게 하고 Git이나 화면에 노출하지 마.

3. 시트 변경과 지연 기록을 확인하는 자동 실행을 설정해줘. 설정하기 전에 실행 주기와 해제 방법을 알려주고 내가 확인하면 진행해줘. 중복 트리거는 만들지 마.
